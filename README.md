## Featured project

### [Enterprise Agent Platform](https://github.com/Oussama-zbir/enterprise-agent-platform)

A production-oriented agent platform with authenticated human-in-the-loop approvals, resumable execution, MCP tool integration, and PostgreSQL-backed task state.

External tools are governed by a locally controlled risk policy rather than trusting their own metadata, while optimistic concurrency protects approval and task transitions from races.

The platform uses a provider-neutral LLM layer and a custom orchestration loop, with Docker Compose, contract testing, and end-to-end CI.
